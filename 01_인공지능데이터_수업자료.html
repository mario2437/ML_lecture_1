PART 1오늘 배우는 것 — 개념 정리

슬라이드 내용을 글로 정리했습니다. 수업 후 복습용으로 읽고, 모르는 말이 나오면 이 페이지에서 찾아보세요.

1. AI는 데이터를 먹고 자란다

유튜브 추천, 얼굴 잠금해제, 번역기, 급식 인원 예측 — 모두 수많은 사례(데이터)를 보고 컴퓨터가 규칙을 스스로 찾아낸 결과입니다. 알고리즘이 아무리 좋아도 데이터가 엉망이면 결과도 엉망입니다(Garbage in, garbage out). 그래서 AI를 배우는 첫걸음은 데이터를 읽는 눈을 기르는 것입니다.

셀행과 열이 만나는 칸의 값 하나3번 학생의 성적 79.5. 비어 있으면 결측

5. 숫자로 요약하기 — 대표값과 퍼짐

통계량뜻언제 쓰나
평균 (mean)값을 다 더해 개수로 나눔대칭이고 이상치가 없을 때
중앙값 (median)크기순으로 세워 한가운데 값이상치가 있거나 한쪽으로 치우쳤을 때 (용돈, 소득)
표준편차 (std)평균에서 떨어진 정도의 평균적 크기. 클수록 넓게 퍼짐"같은 평균 70점"인 두 반이 얼마나 다른지 비교
사분위수 (Q1, Q2, Q3)25%, 50%, 75% 지점. Q2 = 중앙값. IQR = Q3 − Q1상자그림의 상자
최소/최대 (min/max)가장 작은/큰 값이상치 의심: 하루 스마트폰 24시간?
IQR 규칙 (상자그림의 이상치)Q1 − 1.5×IQR 보다 작거나 Q3 + 1.5×IQR 보다 크면 이상치 후보로 봅니다. 상자그림에서 수염 밖의 ○ 점이 바로 이 값들입니다. 실습 셀 6에서 이 규칙을 코드로 씁니다.

7. 상관계수 r — 관계의 방향과 세기

  • r은 −1 ~ +1 사이. 부호는 방향(같이 커지면 +, 반대로 움직이면 −), 크기는 세기.
  • |r| 0.7 이상 강함 · 0.3~0.7 중간 · 0.3 이하 약함 (대략의 기준).
  • 실습 데이터: 공부시간↔성적 +0.63, 스마트폰시간↔성적 −0.35, 운동시간↔성적 ≈ 0.
상관 ≠ 인과아이스크림 판매량과 물놀이 사고 수는 상관이 높지만, 아이스크림이 사고를 일으키지 않습니다. 더운 날씨(숨은 변수)가 둘 다 늘립니다. "공부시간↔성적 r=+0.63"도 "공부가 성적을 올린다"의 증명이 아닙니다. 상관은 "같이 움직인다"까지만 말합니다.

예제 2 · 평균·중앙값·표준편차 — 이상치의 효과

예제 4 · 히스토그램과 산점도

import matplotlib.pyplot as plt, numpy as np
rng = np.random.default_rng(0)
x = rng.normal(6.5, 1.0, 100)         # 평균 6.5, 표준편차 1.0인 값 100개

ax[0].hist(x, bins=12); ax[0].set_title('histogram')

plt.show()

2데이터 만들기
make_student_data() 함수는 가상의 고등학생 200명 데이터를 만듭니다. np.random.default_rng(seed)에서 seed(씨앗값)를 2026으로 고정했기 때문에 누가 실행해도 똑같은 표가 나옵니다(실험 재현의 기본). 성적은 공부시간↑·스마트폰↓·수면 적당·아침식사에 따라 만들어졌고 잡음(noise)을 더했습니다.
마지막 6줄이 중요합니다: 수면시간 6칸·운동시간 4칸을 일부러 비우고(np.nan), 17번 학생 스마트폰 24시간, 93번 학생 공부 15시간이라는 말도 안 되는 값을 심었습니다. 현실 데이터에 늘 있는 문제를 연습하기 위해서입니다.
볼 것: df.shape가 (200, 8) — 200명, 변수 8개. df.head(10)은 앞 10명. 빈칸은 NaN으로 표시됩니다.

def make_student_data(n=200, seed=2026):
    rng = np.random.default_rng(seed)                     # 난수 생성기 (seed 고정 → 누구나 같은 데이터)
    sleep = np.clip(rng.normal(6.5, 1.0, n), 3.5, 9.5)      # 수면시간(시간)
    study = np.clip(rng.normal(2.5, 1.2, n), 0, 7)          # 하루 공부시간(시간)
    phone = np.clip(rng.normal(3.5, 1.3, n), 0.3, 8)        # 스마트폰 사용시간(시간)
    exercise = np.clip(rng.normal(2.0, 1.5, n), 0, 8)       # 주당 운동시간(시간)
    breakfast = rng.choice(['먹음', '안먹음'], n, p=[0.6, 0.4])   # 아침식사 여부
    gender = rng.choice(['남', '여'], n)
    grade = rng.choice([1, 2, 3], n)                        # 학년
    # 성적: 공부시간 ↑, 수면 적당 ↑, 스마트폰 ↑ 이면 ↓ + 잡음
    score = 55 + 6.0 * study - 2.5 * phone + 2.0 * (sleep - 6.5) - 1.5 * (sleep - 7) ** 2 \
            + 3.0 * (breakfast == '먹음') + rng.normal(0, 7, n)
    score = np.clip(score, 20, 100).round(1)
    df = pd.DataFrame({'학년': grade, '성별': gender, '수면시간': sleep.round(1), '공부시간': study.round(1),
                       '스마트폰시간': phone.round(1), '운동시간': exercise.round(1), '아침식사': breakfast, '성적': score})
    # 현실처럼 결측(빈칸)과 이상치(잘못 입력된 값)를 몇 개 심는다
    df.loc[rng.choice(n, 6, replace=False), '수면시간'] = np.nan
    df.loc[rng.choice(n, 4, replace=False), '운동시간'] = np.nan
    df.loc[17, '스마트폰시간'] = 24.0      # 하루 24시간? → 입력 실수
    df.loc[93, '공부시간'] = 15.0         # 하루 15시간 공부? → 의심스러운 값
    df.index.name = '학생번호'
    return df

6이상치 찾기
find_outliers 함수는 IQR 규칙을 코드로 옮긴 것입니다. quantile(0.25)=Q1, quantile(0.75)=Q3, iqr = q3 − q1. 정상 범위는 [Q1 − 1.5×IQR, Q3 + 1.5×IQR]이고 그 밖의 값을 돌려줍니다. (s < low) | (s > high)에서 |는 "또는".
출력을 보면 스마트폰시간 이상치 2개(24.0과 7.7), 공부시간 2개(15.0과 6.1), 성적 1개(24.2)가 나옵니다. 모두 지우면 안 됩니다. 7.7시간, 6.1시간, 24.2점은 드물지만 가능한 값이라 진짜 학생일 수 있습니다. 반면 24시간·15시간은 물리적으로 불가능하므로 입력 실수로 보고 제거합니다.
df_clean.drop(bad.index)로 두 행을 지우면 198명이 됩니다.

def find_outliers(s):
    q1, q3 = s.quantile(0.25), s.quantile(0.75)
    iqr = q3 - q1
    low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    return s[(s < low) | (s > high)]

for col in ['스마트폰시간', '공부시간', '성적']:
    out = find_outliers(df_clean[col])
    print(f'{col}: 이상치 {len(out)}개 →', out.round(1).to_dict())

7평균·중앙값·표준편차
정리 전(df)과 후(df_clean)의 스마트폰시간을 비교합니다. f"..."는 문자열 안에 {s.mean():.2f}처럼 값을 소수 둘째 자리로 끼워 넣는 문법입니다.
