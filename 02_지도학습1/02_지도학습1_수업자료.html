PART 1오늘 배우는 것 — 지도학습과 알고리즘 4가지

한 줄 요약: 지도학습은 정답이 붙은 데이터로 "특징 → 정답" 규칙을 배우는 방법이다. 맞힐 것이 숫자면 회귀, 종류면 분류이고, 알고리즘은 목적(설명이 필요한가? 확률이 필요한가? 관계가 직선인가?)에 따라 고른다.

1-1. 지도학습 = 정답이 붙은 문제집으로 공부하기

유튜브가 내가 좋아할 영상을 고르고, 스마트폰이 사진 속 얼굴을 알아보는 것은 모두 과거의 "정답이 붙은 기록"에서 규칙을 배웠기 때문입니다. "지도(supervised)"라는 말은 선생님(정답)이 옆에서 채점해 준다는 뜻입니다. 정답을 라벨(label)이라고 부릅니다.

용어뜻붓꽃 예시
특징 (feature, X)모델에 넣어 주는 정보 · 입력꽃받침 길이·너비, 꽃잎 길이·너비 (숫자 4개)
라벨 (label, y)맞혀야 하는 정답품종: setosa / versicolor / virginica
모델 (model)특징 → 라벨 규칙을 담는 상자"꽃잎 길이 ≤ 2.5cm면 setosa" 같은 규칙
학습 (fit)데이터로 규칙을 찾는 과정model.fit(X, y)
예측 (predict)새 특징에 규칙을 적용해 답 내기model.predict(새 꽃) → "setosa"
기억할 것데이터 한 줄(행) = 특징들 + 라벨 하나. 라벨이 있으면 지도학습, 없으면 비지도학습(4회차).

1-2. 회귀 vs 분류 — 맞힐 것이 숫자인가, 종류인가

회귀 (regression)

  • 정답이 연속된 숫자: 점수·기온·가격·키
  • "몇 점? 몇 도? 얼마?"
  • 결과는 직선/곡선 같은 함수

분류 (classification)

  • 정답이 정해진 종류: 품종·스팸/정상·합격/불합격
  • "어느 쪽? 무엇?"
  • 결과는 데이터를 나누는 경계선
문제회귀/분류왜?
내일 급식 잔반량(kg)을 메뉴·요일로 맞히기회귀정답이 숫자(kg)
사진 속 동물이 고양이인지 강아지인지분류두 종류 중 하나
문자 메시지가 스팸인지 아닌지분류예/아니오
중고 스마트폰 가격을 연식·용량으로 맞히기회귀정답이 가격(숫자)
손글씨 숫자 이미지가 0~9 중 무엇인지분류10가지 종류 중 하나 (숫자지만 "종류"!)
키·몸무게로 100m 기록(초) 맞히기회귀정답이 초(숫자)
함정 주의"0~9 숫자 맞히기"는 숫자처럼 보이지만 9와 0 사이에 8.5는 없습니다 → 종류를 고르는 분류. 정답 사이에 중간값이 있으면 회귀, 없으면 분류.

1-3. 알고리즘 ① 선형회귀 — 점들과 가장 가까운 직선 하나

선형회귀는 성적 = 기울기 × 공부시간 + 절편 꼴의 직선을 찾습니다. 기울기(coef_)는 "공부시간이 1시간 늘 때 성적이 몇 점 오르는가", 절편(intercept_)은 "공부시간이 0일 때의 시작 점수"입니다. 특징과 정답이 대체로 직선 관계일 때 잘 맞고, 결과를 말로 설명하기 쉽다는 것이 큰 장점입니다.

주의 — 데이터 범위 밖 예측(외삽)하루 20시간 공부를 넣으면 190점처럼 100점을 넘는 엉터리 값이 나옵니다. 모델은 본 적 없는 영역을 모릅니다. 예측은 학습 데이터 범위 안에서만 믿으세요.

1-4. 알고리즘 ② kNN — 가까운 이웃 k개의 다수결

  • 새 데이터와 모든 훈련 데이터의 거리를 잰다
  • 가장 가까운 k개를 고른다 (k=5면 5개)
  • 그중 가장 많은 종류로 답한다 (투표)

규칙을 따로 외우지 않고 "비슷한 것끼리"로 판단하므로 단순하고 직관적입니다. k가 작으면(1) 튀는 값(이상치) 하나에 흔들리고, 너무 크면 모든 것을 뭉뚱그려 "가장 흔한 종류"만 답하게 됩니다. 데이터가 많으면 거리 계산이 느려지는 것이 단점입니다.

1-5. 알고리즘 ③ 결정트리 — "예/아니오" 질문을 이어 가며 나누기

스무고개처럼 데이터를 가장 잘 갈라놓는 질문을 찾고, 나뉜 각 그룹에서 다시 질문을 찾습니다. 정해진 깊이(max_depth)에 닿거나 더 못 나누면 멈추고, 맨 아래 잎(leaf)의 다수 종류가 답이 됩니다. 왜 그렇게 판단했는지 그림으로 보인다는 것이 최대 장점이고, 너무 깊게 파면 훈련 데이터를 통째로 외워 버리는 것(과적합, 3회차)이 단점입니다.

1-6. 알고리즘 ④ 로지스틱 회귀 — "예"일 확률을 S자 곡선으로

이름에 "회귀"가 들어 있지만 하는 일은 분류입니다. 합격/불합격, 스팸/정상처럼 두 가지 중 하나이고 "몇 % 확률인지"까지 알고 싶을 때 씁니다. 결과가 확률이므로 위험도 순위를 매길 수 있습니다. (오늘 실습에서는 직접 돌리지 않고 원리만 배웁니다.)

1-7. 목적에 맞는 알고리즘 고르기

알고리즘문제 유형판단 방식장점 / 단점조절 손잡이(하이퍼파라미터)
선형회귀회귀오차 최소 직선설명 쉬움 / 곡선 관계엔 약함(거의 없음)
kNN분류 (회귀도 가능)가까운 k개 다수결단순·직관 / 데이터 많으면 느림k (이웃 수)
결정트리분류 (회귀도 가능)예/아니오 질문 나무규칙이 보임 / 깊으면 외워 버림max_depth (깊이)
로지스틱 회귀분류 (2종류)점수 → S곡선 → 확률확률 제공 / 복잡한 경계엔 약함(규제 강도 C)
고를 때 더 물어볼 것왜 그렇게 판단했는지 보여 줘야 하나? → 결정트리  |  확률(몇 %)이 필요한가? → 로지스틱 회귀  |  관계가 직선에 가깝나? → 선형회귀  |  비슷한 사례로 판단하면 되나? → kNN  |  정답이 없나? → 비지도학습(4회차)

1-8. 훈련/테스트 분리 — 공부한 문제로 시험 보면 안 된다

모델의 진짜 실력은 처음 보는 데이터에서 재야 합니다. 훈련 데이터로만 fit하고, 테스트 데이터로 score(정확도)를 잽니다. 훈련 정확도만 높고 테스트 정확도가 낮으면 문제집을 외운 것(과적합)입니다. 이것을 잡는 방법은 3회차에서 배웁니다.

PART 2예제 — 개념당 코드 한 토막

실습 전에 "이 정도 코드로 된다"를 눈에 익히는 곳입니다. 모두 Colab 새 노트에 붙여 넣으면 그대로 돌아갑니다. (출력값은 실제 실행 결과)

예제 1. scikit-learn의 3단계 패턴 — 어떤 모델이든 똑같다

python3단계 패턴
from sklearn.linear_model import LinearRegression
import pandas as pd

X = pd.DataFrame({'공부시간': [1, 2, 3, 4, 5]})   # 특징 (표 모양! 대괄호 두 번과 같은 효과)
y = [50, 58, 64, 73, 79]                           # 정답

model = LinearRegression()   # 1) 빈 모델 만들기
model.fit(X, y)              # 2) 학습
print(model.predict(pd.DataFrame({'공부시간': [6]})))   # 3) 예측
print("기울기", model.coef_[0].round(2), "절편", round(model.intercept_, 2))
예상 출력
[86.7]
기울기 7.3 절편 42.9

읽는 법: 5명의 데이터로 직선을 찾았더니 기울기 7.3(1시간당 7.3점), 절편 42.9. 6시간이면 7.3×6 + 42.9 ≈ 86.7점으로 예측. 모델 이름만 KNeighborsClassifier, DecisionTreeClassifier로 바꾸면 분류도 같은 3단계입니다.

예제 2. kNN 분류 — 이웃 투표

pythonkNN
from sklearn.neighbors import KNeighborsClassifier
X = [[1, 1], [1, 2], [2, 1],  [6, 6], [6, 7], [7, 6]]   # 특징 2개
y = ['A', 'A', 'A',  'B', 'B', 'B']                  # 라벨
knn = KNeighborsClassifier(n_neighbors=3).fit(X, y)
print(knn.predict([[2, 2], [6, 5]]))          # 새 점 두 개
print(knn.predict_proba([[4, 4]]))            # (4,4)는 중간 → 투표 결과 확률
예상 출력
['A' 'B']
[[0.66666667 0.33333333]]

읽는 법: (2,2)는 A 무리 근처 → A, (6,5)는 B 근처 → B. 정중앙 (4,4)는 가장 가까운 3개 중 A가 2개, B가 1개라서 확률 [0.67, 0.33] — 다수결로 A.

예제 3. 결정트리 — 배운 규칙을 글로 출력

python결정트리
from sklearn.tree import DecisionTreeClassifier, export_text
X = [[1.4, 0.2], [1.3, 0.2], [4.5, 1.5], [4.7, 1.4], [5.9, 2.1], [6.1, 2.3]]   # 꽃잎 길이, 너비
y = ['setosa', 'setosa', 'versicolor', 'versicolor', 'virginica', 'virginica']
tree = DecisionTreeClassifier(max_depth=2).fit(X, y)
print(export_text(tree, feature_names=['꽃잎길이', '꽃잎너비']))
예상 출력
|--- 꽃잎너비 <= 0.80
|   |--- class: setosa
|--- 꽃잎너비 >  0.80
|   |--- 꽃잎길이 <= 5.30
|   |   |--- class: versicolor
|   |--- 꽃잎길이 >  5.30
|   |   |--- class: virginica

읽는 법: 트리가 스스로 "꽃잎너비 0.8cm"(setosa 가르기)와 "꽃잎길이 5.3cm"(versicolor/virginica 가르기)라는 두 기준을 찾아냈습니다. 사람이 읽고 검증할 수 있는 규칙이라는 점이 결정트리의 힘입니다.

예제 4. 훈련/테스트 분리

pythontrain_test_split
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

읽는 법: 150송이를 섞어 112(훈련) / 38(테스트)로 나눴습니다. random_state=0은 섞는 방식을 고정해 누가 해도 같은 결과가 나오게 합니다.

1A-1. 데이터 만들기 — 학생 40명의 공부시간과 성적
무엇을: 40명의 가상 학생에 대해 하루 공부시간(0.5~6시간)과 성적(0~100점)을 만들어 표(DataFrame)에 담습니다. 파일 업로드가 필요 없도록 코드 안에서 생성합니다.
코드 읽기: np.random.default_rng(2024)는 난수 생성기에 씨앗 2024를 주는 것 — 씨앗이 같으면 누가 실행해도 똑같은 난수가 나옵니다. rng.uniform(0.5, 6, 40)는 0.5~6 사이 숫자 40개, np.round(…, 1)은 소수 첫째 자리 반올림. 성적은 42 + 7.5×공부시간 + 잡음으로 만들었고 np.clip(…, 0, 100)으로 0~100점 사이로 자릅니다. 우리는 이 "숨은 규칙(42, 7.5)"을 모른다고 치고, 모델이 찾아내는지 볼 겁니다. df.head()는 앞 5줄.
출력에서 볼 것: 행, 열 = (40, 2), 그리고 공부시간·성적 두 열의 앞 5줄.
pythonColab 셀 1
rng = np.random.default_rng(2024)                       # 씨앗 고정 → 항상 같은 데이터
hours = np.round(rng.uniform(0.5, 6, 40), 1)             # 하루 공부시간 0.5~6시간, 40명
score = np.clip(np.round(42 + 7.5 * hours + rng.normal(0, 6, 40)), 0, 100)   # 성적 (0~100점)
df = pd.DataFrame({'공부시간': hours, '성적': score})   # 표로 만들기

df.head()

3A-3. 선형회귀 모델 학습(fit)
무엇을: 점들 사이를 지나는 오차가 가장 작은 직선을 찾습니다.
코드 읽기: ① X = df[['공부시간']] — 대괄호 두 번이라 결과가 "표"(40행 1열). scikit-learn은 입력을 항상 표 모양으로 받습니다. ② y = df['성적'] — 대괄호 한 번이라 "한 줄"(정답). ③ model = LinearRegression() 빈 모델, ④ model.fit(X, y) 학습. 학습이 끝나면 model.coef_(기울기, 특징이 여러 개일 수 있어 배열이라 [0]으로 첫 값)와 model.intercept_(절편)에 결과가 들어 있습니다.
출력에서 볼 것: 기울기 7.38, 절편 42.78. 데이터를 만들 때 넣은 규칙(7.5, 42)과 거의 같음 → 모델이 40개의 점만 보고 숨은 규칙을 찾아냈습니다. (정확히 같지 않은 이유: 잡음 때문.)
pythonColab 셀 3
from sklearn.linear_model import LinearRegression

X = df[['공부시간']]     # 입력(특징): 대괄호 2개 → 표 모양 (40행 1열)
y = df['성적']          # 정답(라벨)

model = LinearRegression()   # 1) 빈 모델
model.fit(X, y)              # 2) 학습 — 오차가 가장 작은 직선 찾기

print("기울기 (공부 1시간당 오르는 점수):", round(model.coef_[0], 2))
print("절편   (공부 0시간일 때 점수)    :", round(model.intercept_, 2))

9B-3. 훈련용 / 테스트용으로 나누기
무엇을: 공부한 문제집으로 시험을 보면 점수가 부풀려집니다. 그래서 데이터를 훈련(75%)과 테스트(25%)로 나누고, 테스트는 학습에 절대 쓰지 않습니다.
코드 읽기: X는 특징 4열, y는 품종. train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)가 네 덩어리를 돌려줍니다: X_train, X_test, y_train, y_test(순서 중요!). test_size=0.25 25%를 테스트로, random_state=0 섞는 방식 고정, stratify=y 품종 비율을 훈련/테스트에서 똑같이 유지(안 하면 우연히 한 품종이 테스트에 몰릴 수 있음).
출력에서 볼 것: 훈련 112송이, 테스트 38송이.

from sklearn.model_selection import train_test_split

10B-4. kNN 학습과 테스트 정확도
