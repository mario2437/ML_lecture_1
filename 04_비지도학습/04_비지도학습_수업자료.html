PART 1오늘 배우는 것 — 정답 없는 데이터에서 구조 찾기

지난 두 시간 동안 배운 지도학습은 "문제와 정답"을 같이 주고 배우게 했습니다. 오늘은 정답이 없는 데이터만 주고 "비슷한 것끼리 묶어라", "핵심만 남겨 요약하라"고 시키는 비지도학습입니다.

1. 지도학습 vs 비지도학습

지도학습 (2·3회차)비지도학습 (오늘)
주어지는 것입력 X + 정답 y입력 X만
목표y를 맞히는 규칙 찾기X 안의 구조(무리·축·이상한 점) 찾기
예시사진 → 고양이/개, 공부시간 → 성적고객을 비슷한 유형으로 묶기, 40개 설문을 2개 축으로 요약
정답 채점정확도·MAE 등으로 채점 가능정답이 없으니 사람이 해석해야 함 (실루엣 등 보조 지표)
한 줄 정의비지도학습 = 정답(라벨) 없이 데이터 자체의 패턴·구조를 찾아내는 기계학습. 유튜브가 "이 영상을 본 사람들끼리" 묶어 추천하는 것, 카드사가 평소와 다른 결제를 잡아내는 것이 대표적인 쓰임입니다.

PART 2알고리즘의 원리와 고르는 법

k-means를 손으로 따라가며 이해한 뒤, "k는 어떻게 정하나?", "둥글지 않은 모양이면?", "변수가 너무 많으면?" 세 질문에 답하는 도구를 하나씩 봅니다.

1. k-means — 중심을 놓고, 배정하고, 옮기고, 반복

  • ① 초기화: 군집 개수 k를 정하고 중심 k개를 아무 데나 놓는다.
  • ② 배정: 모든 점을 가장 가까운 중심의 군집에 넣는다.
  • ③ 갱신: 각 군집에 속한 점들의 평균 위치로 중심을 옮긴다. (mean = 평균 → k-means)
  • ④ 반복: 중심이 거의 안 움직이면 끝. 처음 중심을 어디 놓느냐에 따라 결과가 달라질 수 있어 n_init=10처럼 여러 번 시도한다.
거리로 판단하므로 표준화가 필요수면시간(6~8)과 독서시간(0~2)처럼 크기가 다른 변수를 그냥 쓰면 값이 큰 변수가 거리를 독차지합니다. StandardScaler로 각 변수를 평균 0·표준편차 1로 맞춘 뒤 군집화하는 것이 기본입니다.

2. k는 몇 개? — 엘보 곡선과 실루엣 점수

방법무엇을 재나읽는 법주의
엘보 곡선inertia = 각 점에서 자기 중심까지 거리²의 합k를 늘릴 때 확 꺾이는 지점꺾임이 애매할 때가 많음
실루엣 점수(다른 군집과의 거리 − 내 군집과의 거리)를 −1~1로가장 높은 k. 0.5 이상이면 꽤 뚜렷k=1은 계산 불가, 데이터가 크면 느림

3. 둥근 덩어리가 아니라면 — 계층적 군집과 DBSCAN

기법핵심 아이디어k 필요?잘 맞는 모양약점
k-means중심 k개를 반복해서 옮김필요둥근 덩어리, 크기 비슷모양이 길거나 크기가 다르면 실패, 이상치에 민감
계층적 군집가까운 것부터 합쳐 나무(덴드로그램)나중에 자르면서 결정작은 데이터, 계층 구조 보기데이터가 크면 매우 느림
DBSCAN반지름 eps 안에 이웃 min_samples개 이상이면 같은 무리불필요이어진 모양, 잡음 섞임eps 정하기 어려움, 밀도가 다르면 실패
PCA가장 넓게 퍼진 방향으로 새 축축 개수변수가 많을 때 요약·시각화군집을 만드는 기법은 아님(전처리·시각화용)

4. 변수가 많다면 — PCA로 2차원에 그리기

  • PC1은 데이터의 퍼짐(정보)을 가장 많이 담는 방향, PC2는 그 다음 (PC1과 직각).
  • explained_variance_ratio_ = 각 축이 담는 정보의 비율. PC1+PC2가 60~80%면 2차원 그림을 꽤 믿을 수 있다.
  • 6개 변수의 학생 데이터도 PCA로 2차원에 그리면 군집이 눈에 보인다 (아래 그림).
목적에 맞는 기법 고르기 — 오늘의 성취기준① 무리를 나누는가(군집) / 요약하는가(차원축소) / 이상한 점을 찾는가(이상치) → ② 군집이면 k를 아는가, 데이터 모양이 둥근가·이어졌는가, 데이터가 큰가 → ③ 표에서 기법을 고르고 근거를 말할 수 있어야 합니다.

2STEP 2. k-means로 4개 군집 나누기
KMeans(n_clusters=4, n_init=10, random_state=0): 군집 4개, 초기 중심을 10번 다르게 시도, 난수 고정. fit_predict(X)는 학습과 동시에 각 점의 군집 번호(0~3)를 돌려줍니다. np.bincount(labels)는 번호별 개수를 세는 함수입니다(75, 74, 75, 76처럼 고르게 나오면 잘 나뉜 것). cluster_centers_는 최종 중심 좌표 4개(각각 x, y). 그림에서 c=labels는 군집 번호에 따라 색을 칠하라는 뜻, 검은 X는 중심입니다.
pythonColab 셀 2
from sklearn.cluster import KMeans

km = KMeans(n_clusters=4, n_init=10, random_state=0)
labels = km.fit_predict(X)             # 각 점의 군집 번호
centers = km.cluster_centers_          # 군집 중심 좌표

print("군집 번호(앞 10개):", labels[:10])
print("군집별 점 개수:", np.bincount(labels))
print("중심 좌표:\n", centers.round(2))

plt.figure(figsize=(5, 4))
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='tab10', s=15)                  # 군집별 색
plt.scatter(centers[:, 0], centers[:, 1], marker='X', s=200, c='black', label='중심')

6STEP 6. 학생 생활 유형 데이터 만들기
함수 make_student_types가 학생 150명의 하루 생활 시간(6개 변수)을 만듭니다. 내부에는 숨은 유형 3개의 평균이 있지만 결과 표에는 유형 이름이 없습니다 — 이걸 우리가 찾아내는 것이 과제입니다. rng.normal(c, sd, size=(50, 6))는 평균 c·표준편차 sd인 값을 50명×6변수만큼 뽑고, np.clip(..., 0, None)은 음수 시간을 0으로 만듭니다. sample(frac=1)은 순서를 섞습니다. describe()는 열마다 개수·평균·표준편차·최소·사분위·최대를 요약합니다.

def make_student_types(n_per=50, seed=2026):
    rng = np.random.default_rng(seed)
    centers = {                      # 숨겨진 유형 3개의 '평균 생활' (학생들은 이 이름을 모름)
        'A': [6.5, 5.0, 0.7, 0.5, 1.0, 1.2],
        'B': [6.0, 1.5, 4.0, 0.3, 1.5, 0.3],
        'C': [7.5, 2.0, 1.0, 2.5, 3.0, 0.5],
    }
    sd = np.array([0.7, 0.8, 0.7, 0.5, 0.7, 0.4])
    rows = [np.clip(rng.normal(c, sd, size=(n_per, 6)), 0, None) for c in centers.values()]
    cols = ['수면시간', '공부시간', '게임시간', '운동시간', 'SNS시간', '독서시간']
    df = pd.DataFrame(np.round(np.vstack(rows), 1), columns=cols)
    return df.sample(frac=1, random_state=seed).reset_index(drop=True)   # 섞기

students = make_student_types()
print("학생 수, 변수 수:", students.shape)
display(students.head())
display(students.describe().round(2))

PCA(n_components=2).fit_transform(Xs)가 표준화된 6차원을 2차원 Z로 바꿉니다. explained_variance_ratio_가 [0.401, 0.375]이므로 두 축이 전체 정보의 약 78%를 담습니다. 그림에서 군집 색이 세 무리로 나뉘어 보이면 군집이 실제로 구분된다는 뜻입니다. 마지막 표(components_)는 각 PC가 어떤 변수로 만들어졌는지 보여 줍니다: PC1은 운동(0.59)·SNS(0.55)·수면(0.46)이 크고, PC2는 공부(0.56)·독서(0.55)가 크며 게임(−0.55)은 반대 방향입니다. 즉 PC2 값이 크면 "공부·독서형", 작으면 "게임형"입니다.

12STEP 11. 계층적 군집 덴드로그램

13STEP 12. 초승달 데이터 — k-means vs DBSCAN
make_moons는 초승달 두 개가 얽힌 데이터를 만듭니다. k-means(k=2)는 둥근 덩어리를 가정해 초승달을 가로로 잘라 버리고, DBSCAN(eps=0.2, min_samples=5)는 "반지름 0.2 안에 이웃 5개 이상이면 같은 무리"라는 규칙으로 초승달 모양을 그대로 따라갑니다. np.unique(lab_db)에 −1이 있으면 어디에도 속하지 못한 잡음 점입니다(여기서는 없음).

Q1. 비지도학습에 대한 설명으로 옳은 것은?
정답: ② — 비지도학습은 라벨 없이 데이터 자체의 패턴을 찾습니다. ①은 지도학습, ③은 강화학습(다음 시간)입니다.
Q2. k-means의 한 번 반복(iteration)에서 하는 일을 순서대로 고르면?
정답: ② — 배정 → 갱신(평균으로 이동)을 반복합니다. ③은 계층적 군집, ④는 DBSCAN입니다.
Q3. 엘보 곡선에서 군집 개수 k를 고르는 기준은?
정답: ③ — inertia는 k가 커질수록 계속 줄어들므로 최소값을 고르면 k=점 개수가 됩니다. 꺾이는 지점(팔꿈치)이 후보 k입니다.
Q4. 수면시간(6~8)과 독서시간(0~2)으로 k-means를 할 때 먼저 해야 할 일은?
정답: ② — k-means는 거리로 판단하므로 값 범위가 큰 변수가 결과를 독차지합니다. 표준화(평균 0·표준편차 1)가 기본 전처리입니다.
Q5. 배달 주문 위치가 길을 따라 길게 이어진 모양으로 몰려 있다. 몰린 구역을 찾기에 가장 알맞은 기법은?
정답: ② — 둥근 덩어리가 아니라 이어진 모양·밀도 기반 문제이므로 DBSCAN이 적합합니다. k-means는 둥근 덩어리를 가정하고, PCA는 차원 축소, 선형 회귀는 지도학습입니다.
